# Lampino — დემო საიტი
n**ცოცხალი:** https://tikadzenika-bit.github.io/lampino/ · რეპო: https://github.com/tikadzenika-bit/lampino

ერთგვერდიანი საიტი Lampino-სთვის (ქეთი ნოზაძის ხელნაკეთი ლამპები ძველი თბილისის მოტივებით). ენები: ქართული (ძირითადი) და English. ეს არის **დემო / კონცეფცია**: ფოტოები და ფასების ნაწილი ნიმუშია.

## როგორ გავხსნა

`index.html`-ზე ორჯერ დააწკაპუნე — გაიხსნება ბრაუზერში. ინტერნეტი საჭიროა მხოლოდ ფონტებისა და რუკისთვის.

ინგლისური ვერსიის პირდაპირი ბმული: მისამართის ბოლოს დაამატე `?lang=en`.

## რა უნდა შეცვალოს მფლობელმა

1. **ფოტოები** — ახლა ყველა სურათი დახატული ნიმუშია წარწერით „ნიმუში · placeholder“. ნამდვილი ფოტო იმავე სახელით ჩააგდე `images/` საქაღალდეში (მაგ. `lamp-1.jpg`) და საიტზე თავისით შეიცვლება. სია: `images/README.md`.
2. **ფასები** — `js/main.js` → `PRODUCTS` → `price`. ვარსკვლავიანი ფასები გამოგონილი ნიმუშია (`sample: true`). ნამდვილი ფასის ჩაწერის შემდეგ დაწერე `sample: false` და ვარსკვლავი გაქრება. ნამდვილია მხოლოდ „15 ₾-დან“ (პატარა ნივთები).
3. **ნივთების სახელები და აღწერები** — იქვე, `ka` და `en`. ახლანდელი სახელები ჩვენი შერჩეულია.
4. **მიწოდება** — ფუტერის წინადადება (`TEXT` → `ft.ship`, ორივე ენაზე): რომელ ქვეყნებში, რა ვადაში, რა ფასად.
5. **Etsy-ის ბმული** — `index.html`-ში ფუტერთან დევს `<!-- TODO -->`; როცა ბმული იქნება, იქ დაემატება.
6. **ინდივიდუალური შეკვეთის ვადა და ფასი** — ახლა გვერდზე არ წერია.
7. **ქეთის ფოტო** — `images/keti.jpg`.

ყველა ასეთი ადგილი კოდში მონიშნულია სიტყვით `TODO` (მოძებნე Ctrl+F-ით).

## დემო ბანერის მოხსნა

`index.html`-ში წაშალე ერთი ხაზი, რომელიც ასე იწყება: `<p class="demo-banner"`.

## ახალი ნივთის დამატება

`js/main.js` → `PRODUCTS`-ში დააკოპირე ერთი ბლოკი `{ ... },` და შეცვალე: `id` (ლათინურად, უნიკალური), `cat` (`lamps` / `night` / `souvenirs`), `img`, `price`, `ka` და `en`. „მალე“ ნივთს `price`-ის ნაცვლად უწერია `soon: true`.

## GitHub-ზე ატვირთვა და GitHub Pages

1. შედი [github.com](https://github.com)-ზე შენი ანგარიშით. ზემოთ მარჯვნივ **+ → New repository**.
2. **Repository name**: `lampino`. აირჩიე **Public**. დააჭირე **Create repository**.
3. გახსნილ გვერდზე დააჭირე **uploading an existing file**.
4. კომპიუტერიდან გადაათრიე ამ საქაღალდის მთელი შიგთავსი: `index.html`, `README.md` და საქაღალდეები `css`, `js`, `images`. დააჭირე **Commit changes**.
5. რეპოზიტორიაში გახსენი **Settings → Pages**.
6. **Source**: `Deploy from a branch`. **Branch**: `main` და `/ (root)`. დააჭირე **Save**.
7. 1–2 წუთში საიტი გაიხსნება მისამართზე `https://შენი-სახელი.github.io/lampino/`.

### გაზიარების სურათი (WhatsApp-ის პრევიუ)

`index.html`-ის თავში ოთხ ადგილას წერია მისამართი `https://tikadzenika-bit.github.io/lampino/` (`canonical`, `og:url`, `og:image`). თუ საიტი სხვა მისამართზე გამოქვეყნდა, ეს მისამართი ყველგან შეცვალე ნამდვილით — სხვაგვარად WhatsApp-ში ბმულს სურათი არ გამოუჩნდება.

## დომენის lampino.ge მიბმა (მოგვიანებით)

1. იყიდე `lampino.ge` რეგისტრატორთან.
2. საიტის საქაღალდეში (იქ, სადაც `index.html` დევს) შექმენი ფაილი სახელით `CNAME` (გაფართოების გარეშე), შიგნით ერთი ხაზი: `lampino.ge`. ატვირთე GitHub-ზე.
3. რეგისტრატორის DNS პარამეტრებში დაამატე ჩანაწერები:

   | ტიპი | სახელი | მნიშვნელობა |
   | --- | --- | --- |
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |
   | CNAME | www | `შენი-სახელი.github.io` |

4. GitHub-ზე **Settings → Pages → Custom domain**: ჩაწერე `lampino.ge`, **Save**. რამდენიმე საათში, როცა შემოწმება დასრულდება, მონიშნე **Enforce HTTPS**.
5. `index.html`-ში `canonical`, `og:url` და `og:image` შეცვალე `https://lampino.ge/`-ით.
